# 叙事与节奏

来源：`hyperframes-creative/references/story-spine.md`、`beat-direction.md`、`narration.md`。

上一篇解决「画面好不好看」，这一篇解决「看不看得下去」。review 里那句「这些只改善观感，不保证播放量」——真正决定留存的部分在这里。

## 钩子用结果语言

第一拍回答的是「我为什么要关心」，要用**结果语言**：观众获得什么、避免什么、终于看懂了什么。

- 钩子里禁用主体内部词汇：代码视频里的文件名/函数名、产品视频里的功能列表、解释视频里的原文小标题。
- 数字只有在**带赌注**时才能进钩子（「冷启动快 40%」），不能是清单（「改了 23 个文件」）。

对 Heron：钩子不能是「本期解读某某数据集」，得是观众能拿走的那句话。

## 反向冰山：价值先于证据

价值主张（这条片子要说的事）**最晚第二拍就要落地**。之后所有内容都是支撑它的证据——数据、机制、对比、来源截图。

自检方式：

- 删掉所有证据拍，剩下的拍子仍能独立说清价值吗？
- 删掉所有价值拍，如果片子还像样，那它就不是故事，是一个功能巡礼。

结构上价值优先，**语气**可以是克制的。先讲价值是排序决定，不是营销话术。

## 分镜是一份提案，不是清单

分镜表每行都要能回答「这一帧在故事里干什么」：

| 帧 | 节拍 | 画面 | 为什么 |
| - | - | - | - |
| 01 | 钩子 · 9s | 说出旧的痛点并在同一口气里解掉 | 第一拍落价值主张 |

「为什么」要能追溯到那条价值主张。**追溯不到的帧，是应该砍掉的帧，不是应该装饰的帧。**

## 视觉要指回来源

当片子来自具体材料（新闻、数据集、报告），先从材料里挖视觉语汇，再谈发明：它的措辞、实体、动词、反复出现的意象，就是你的道具。

每一帧的关键视觉都应该能追溯到材料里的某一句具体内容——真实的字段名而不是通用的文件图标，这份数据自己的数字而不是编的数字，原文自己的比喻而不是公共素材。

自检：这个道具能否原样出现在另一个产品的视频里？能，就说明它不是从材料长出来的，换掉再装饰。

## 每一拍是一个世界，不是一张版式

分镜写像素之前，先写观众**经历**到什么。差别：

- **平庸**：「深蓝背景。`$1.9T` 白色 280px。Logo 左上。波浪图右下。」
- **好**：「镜头已经在暗色画布上方飞行。渐变波浪像极光一样扫过画面——活的、在变。`$1.9T` 砸进画面，力道大到波浪为之荡开。这不是一张幻灯片，是一个时刻。」

先写后者，再把它翻译成像素。

每一拍要有六件事：

1. **概念**——2–3 句说清这是个什么世界、什么隐喻、观众该感觉到什么。最重要，其余都从这里长出来。
2. **情绪方向**——用文化和设计参考，不是色值：「几何、有节奏、精确，想起 Josef Albers 或包豪斯的色彩研究」。
3. **动效编排**——每个元素一个动词（见 [motion-and-transition.md](motion-and-transition.md) 的动词表），不是「它动了」，是**怎么动**。
4. **转场**——这一拍怎么交给下一拍，连类型和参数一起定。
5. **纵深层次**——前景/中景/背景分别是什么。每一拍至少两层。
6. **音效点**——什么声音在什么时刻。

## 节奏要先命名再实现

写 HTML 之前先声明这条片子的节奏型：哪几拍是快切、哪几拍是停留、Shader 落在哪、能量峰在哪。

把模式念出来：`快-快-慢-快-SHADER-停`。

节奏从故事和品牌推导，不是查表。两支 15 秒广告可以是完全不同的节奏：一支「慢揭示-停-CTA」，一支「连击-SLAM-钩子」。视频类型只给约束（时长、大致拍数），**快慢疏密戏剧性由内容和品牌决定**。

驱动节奏的问题：

- 观众该经历什么情绪旅程？峰值在哪一拍？
- 旁白最重的那句落在哪？那里通常就是能量峰。
- 品牌自身的视觉步调是从容还是紧迫？
- 这个时长实际能承载几拍，才不显得赶或注水？

15 秒里想塞进「2 秒钩子 + 3 个功能 + CTA」，结果只会是噪音。有时候「钩子-停留-CTA」加一个强功能，才是 15 秒的正解。

## 固定阅读时间

屏幕上停 3 秒 = 必须 2 秒读完。字更少、更大。这条在竖屏里尤其狠——观众的手指随时在往上滑。

## 旁白与字幕不是同一件事

- 旁白负责**论证**（为什么这个数据重要）。
- 字幕负责**可读**（说了什么），并且是静音观看时的唯一信息源。

数字的口播处理（读法、单位、约数）归旁白；屏幕上的数值归画面。两者不一致是最常见的可信度杀手——口播说「接近三成」，画面写 `31.7%`，观众会开始怀疑。
