## 意图

排行榜最容易犯的错是「一整张表淡入」——观众同时收到 5 行，一个都没记住。
这张卡把「座次」做成**物理顺序**：条目按名次从高到低依次从左侧弹射入位，
入位次序就是名次次序，观众被迫先看第一名。领跑者入位后戴冠标定格，
后续条目错峰跟进——落定时观众已经读过前三名。

真正的手感命门有三：

1. **弹射只有一次**。整场一次「从左轨冲入」的入场，名次换位不重复弹射——
   重复弹射读作 bug 回放，不是比赛。
2. **错峰是名次本身**。第一名先到，第二名跟 0.12s，往后每行 +0.08s——
   到达顺序就是排名，这个信息不需要旁白。
3. **位移动画落在子元素**。带 `data-start` 的 clip 由引擎接管 transform，
   对 section 本身 set x 会被忽略（motion.js 注释里的实测）；换位必须动 `.row` 子元素。

## 动作阶段

| 阶段 | 时窗参考 | 内容 |
|------|------|------|
| 1 榜单入场 | 每屏 start + 0.1s | `.row` 从左轨 x:−120px 依次弹射入位（power3.out，首行 at=+0.1，此后每行 +0.08s 错峰） |
| 2 数字滚动 | 每行入位后 0.05s | 行内数值从 0 滚到事实值（gsap innerText snap，precision 随 dataset） |
| 3 戴冠 | 首行入位后 0.3s | `.crown`（「领跑」角标）scale 0→1.06→1 弹出，锁定在第一行行首 |
| 4 sparkline 生长 | 每行入位后 0.1s | 行尾迷你走势线 scaleX 0→1（transform-origin: left），长度 1.2s |
| 5 静止收尾 | 每屏末 0.6s | 全榜定格，无尾漂（「数据图表尾漂读作还没播完」，chart-live-moves 的坑原样适用） |

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 弹射距离 | −120px | <80px 读不出「冲」；>180px 小屏上糊 |
| 错峰步长 | +0.08s | 齿轮感全靠它；>0.15s 读作逐个展示，<0.04s 读作齐发 |
| 戴冠时机 | 首行入位后 0.3s | 早了冠标先于第一名出现，次序就崩了 |
| 数字滚动 | 1.1s，snap 0.01 步进 | 慢于 1.4s 观众会去读中间值，快于 0.8s 读作跳变 |
| sparkline 生长 | scaleX 1.2s ease-out | 从右长会读作「擦除」；必须 origin: left |
| 换位动画 | 若有 focus 换位需求，y 位移 + spring 过冲 | 第一版不做：位移动画先不上，弹射+戴冠已够表达「座次」 |

## 已知坑

- demo 参数是 shotcraft 卡片调校的起点（chart-live-moves / gauge-readout 的参数表移植），
  首次实战必须以真实 dataset 快照回验，逐行读数 ≥32px。
- 事实不够就不画榜——`items` 空或 <2 条时 race 不接管，退回普通文字屏
  （compare.js「宁可这一屏只有文案」的同款诚实原则）。
- 换位动画（名次互换时整列位移）刻意留到下一版：它需要帧级排序快照，
  第一版先把「入场即名次」做稳。
- 声音无：HyperFrames 管线暂无逐动作音效通道，不硬造。
